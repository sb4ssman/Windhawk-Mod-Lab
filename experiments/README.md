# Lab experiments

Local candidates and prototypes, separate from published mods:

- `confirmation-lights/`: configurable read-only detectors, a native Windows
  panel/tray circle, and DCG-only mode. Colors are selectable.
- `icon-hosting/`: OmniButton/Quick Settings anchor inspection and an external
  icon-overlay feasibility prototype. Native injection remains a later stage.
- `stats-dashboard/`: customizable retro instrument dashboard, explicitly using
  simulated data, with square/rectangular widgets and saved layouts.

Nothing here installs itself, changes published mods, or registers startup tasks.
Each folder has instructions and current limitations. Human live verification is
still required for the Windows UI experiments.
