Privacy Indicator Trigger Test

Run from a localhost server (use privacy-trigger-server.ps1). Each section triggers the corresponding Windows privacy indicator while the capture is active.

🧭 Permission & Device Diagnostics

These probes mostly exercise permission prompts rather than taskbar privacy glyphs. They help separate browser permission state from Windows tray indicator state, and they reveal which APIs are available on the test machine.

🎤 Microphone

● Active

The Windows microphone tray icon should appear (or brighten if the Privacy Anchor mod is running) while capture is active.

📷 Camera / Webcam

● Active

Camera tray indicator is off by default in Windows 11. To enable it, set NoPhysicalCameraLED = 1 (DWORD) at HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentPolicies\ and restart, or use a device that has no hardware camera LED (Windows will show the software indicator automatically). The Privacy Anchor mod's camera placeholder is experimental — its dim/bright state will only change if Windows surfaces a camera glyph in the tray.

🎤 + 📷 Microphone & Camera together

● Active

Tests the combined mic+location glyph (0xF47F) that Windows shows when both are active simultaneously. Also good for verifying grid layouts in the Privacy Anchor mod.

📍 Location

● Watching

Requires Windows location permissions and browser permission. The location tray icon appears while Windows is actively resolving position. "Watch location" keeps the indicator active longer.

🖥️ Screen Capture (getDisplayMedia)

● Active

Uses getDisplayMedia to capture the screen. Windows 11 may show a screen-recording tray indicator while active — check the Windhawk log for any unknown glyph code points logged by the Privacy Anchor mod. You will be asked to pick a screen/window to share; pick anything and click Share.

📡 Presence Sensing & Voice Activation (manual)

Presence sensing uses the IR camera to detect whether someone is at the PC (auto-lock / wake). There is no browser API for this. To trigger it manually: Settings → System → Power & sleep → Screen → "Turn off when I look away" (if the device supports it). The tray indicator glyph, if any, will appear in the Windhawk log.

Voice activation (always-on wake word) is controlled in Settings → Privacy & security → Voice activation. Enabling "Let apps use voice activation" while a compatible app is running may surface a tray glyph. Log any unknown code points that appear.
