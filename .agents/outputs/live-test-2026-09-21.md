# Live test — all six mods, round 4/5 review fixes (2026-09-21)

Build: the lab working tree after the round-4/5 review work. Every mod is
`SUBMISSION_PREFLIGHT_OK`. Install each lab `.wh.cpp` over the installed copy.

**Expect a one-time settings reset** for Folder Menus, Tray Utility and VD
Switcher: the old-settings bridge is removed. Copy each mod's settings in
Textual mode before installing, then re-enter them in the 2.0 groups.

Shared-code changes that touch several mods at once:
- UI-thread dispatch: a callback can no longer run twice when two dispatches
  overlap (all six).
- Tray slot lease: a leftover marker from a failed unload is now cleared
  instead of blocking the mod until Explorer restarts (Privacy, Folder, Tray).

## 1. Privacy Indicator Anchor

1. Default settings: all four icons show; Windows' own pop-in indicators hidden.
2. `Content → Camera` off, then open the camera app: Windows' native camera
   indicator must appear (it used to be hidden with nothing replacing it).
3. All four `Content` items off: every native indicator visible, no bar.
4. Change a few settings, disable and re-enable the mod: no native indicator
   left hidden.
5. Glow on and off, several styles.
6. Copilot slash still correct after a Store app update (Copilot re-checks are
   now batched, up to 2 s delay).

## 2. Taskbar Folder Menus

1. Enable the mod on a running Explorer with "Use native Shell icon" on:
   icons appear without an Explorer restart, and there is no label-then-icon flash.
2. Toggle "Use native Shell icon": icons follow.
3. Right-click an item → Delete, leave the confirmation open, disable the mod:
   unload waits; answer the dialog; no crash.
4. Same with a folder popup left open, then disable: the popup closes and the
   mod unloads cleanly.
5. Desktop menu: no duplicate shortcuts.
6. Settings reset once (expected) — re-enter your folders.

## 3. Tray Utility Customizer

1. Restart Explorer (or sign out and back in): the group applies even when the
   tray fills in late (it used to give up after the first attempt).
2. Emoji / touch-keyboard toggled in taskbar settings: the layout follows within
   about half a second.
3. Disable and re-enable: the tray returns exactly as it was.
4. Settings reset once (expected).

## 4. VD Switcher

1. Buttons, labels, Task View button, switching desktops: all as before.
2. Change a setting: the bar rebuilds with the new values.
3. Hover previews: untitled windows now appear; the footer counts every window.
4. If you have a second monitor with `Placement.AllTaskbars` on: hover a

5. Settings reset once (expected).

## 5. Taskbar Clock Spacer

1. Your existing `%s%` clock looks as before.
2. If you use TCC "Line height": a spaced multi-line block now has the same
   line spacing as an unspaced one.
3. With TCC "Text spacing" set, check in UWPSpy whether an extra gap appears

4. Disable and re-enable the mod: the clock returns to native cleanly.
