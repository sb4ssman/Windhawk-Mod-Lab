# Live test — 2.1 pass: every taskbar edge (2026-10-04)

Replaces [live-test-2026-09-22.md](live-test-2026-09-22.md); its items are
folded in below, since those fixes were never installed.

Build: lab working tree, every mod `SUBMISSION_PREFLIGHT_OK`, Windows
26300.9550. Install each lab `.wh.cpp` over the installed copy. No setting keys
changed. **Privacy Indicator Anchor installs as a new mod** (its `@id` is now
`privacy-indicator-anchor`); there is no old copy installed to remove.

How to move the taskbar: Settings → Personalization → Taskbar → Taskbar
behaviors → position. A move is NOT an Explorer rebuild — the mods must follow
it live, which is the main thing under test. Also try once: move, then restart
Explorer while on the side (that is PeTomczyk's case for Folder Menus).

For every mod, at each edge: **Bottom → Left → Right → Top → Bottom.**

| Edge | What should happen |
|---|---|
| Bottom | Exactly as before 2.1 |
| Left / Right | The mod's group appears, arrangement transposed (`\|` runs down, `,` across), left and right identical (no mirroring) |
| Top | Same as bottom |
| Back to Bottom | Original layout returns, nothing left over |

Watch the Windhawk log for each mod: one "edge or thickness changed" line per
move, no repeating lines while idle.

1. Side: network/volume/battery/percent arranged in the button, which grows
   taller if the arrangement needs more than one line (Windows pins it at 38).
2. Side, `auto`: items fill across the taskbar's width.
3. Battery percentage on and off, on a side taskbar.
4. Bottom (Sept 22): normal arrangement, percentage updates; idle log has no
   repeating "Native OmniButton items changed - re-applying".

## 2. Tray Utility Customizer

1. Side: group placed in the tray column at your Position.
2. Left of Start / Right of Start on a side taskbar: group above / below Start,
   Start and the app buttons pushed down, not overlapped.
3. Bottom (Sept 22): hide the emoji panel so only the touch keyboard is in the
   tray area — the keyboard keeps its own slot. A call/voice recording
   (microphone indicator) does not re-apply the layout each time.

## 3. Privacy Indicator Anchor

1. Shows as **Privacy Indicator Anchor** in Windhawk.

   suppressed and mirrored.

4. Bottom (Sept 22): with the mic in use, disable the mod — the native mic
   indicator comes back.
