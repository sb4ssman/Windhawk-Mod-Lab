# System Tray Grid Lines

Concept notes for a future Windhawk mod that would add user-controlled visual
grid lines in the Windows system tray.

## Goal

Create visible separators between major tray sections and optional minor grid
lines inside dense tray layouts. This is intended as a visual alignment aid for
multi-row taskbars and heavily customized tray setups.

## Current State

This folder is a placeholder/concept folder, not an implemented mod yet.

- [note.md](note.md) - original idea capture

## Possible Directions

- Section dividers between notification icons, OmniButton, clock, Show Desktop,
  and custom injected controls
- Minor grid lines for two-row tray layouts
- User settings for color, opacity, thickness, and placement
- Compatibility with other mods in this repo that inject into `SystemTrayFrameGrid`
